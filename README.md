# Student Grade Calculator – AI-Assisted Python Application

## 1. Project Title

**Student Grade Calculator Using AI-Assisted Development**

## 2. Aim

To develop a Python application using an AI coding assistant such as
GitHub Copilot, Cursor, or Claude Code by following specification-first
development and documenting the AI assistance used during development.

## 3. Problem Statement

Develop a Python application that accepts marks for three subjects,
calculates the total and average marks, and assigns a grade based on
the average.

## 4. Specification

### Input

The program accepts marks for three subjects.

### Grading Rules

| Average Marks | Grade |
|---------------|-------|
| 90 - 100 | A |
| 80 - 89 | B |
| 70 - 79 | C |
| 60 - 69 | D |
| Below 60 | F |

### Output

The application displays:

- Total marks
- Average marks
- Grade
